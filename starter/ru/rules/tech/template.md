## API

Контракт сервиса можно приложить файлом рядом с документом: `tech/<ключ сервиса>.openapi.yaml` (OpenAPI 3) или `tech/<ключ сервиса>.proto` (proto3). Ключ — сервис из таблицы архитектуры. Hammurapi показывает контракт на гейте и передаёт его генерации кода.

Эндпоинты, тела запросов, коды ошибок, права доступа. Пути и имена — дословно: по ним спецификацию находит поиск.
